

## 一、哈希表
> 适用场景：快速查找、去重、分组、统计频次；O(1)查找，空间换时间

### 1. 1. 两数之和（简单）
**题目**：给定数组nums和目标值target，返回和为target的两个元素下标
**核心思路**：哈希字典保存【数值:下标】，遍历每个数，查询 `target - 当前值` 是否存在哈希表
**易错点**：先查询再存入哈希，避免同一个元素重复使用
```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        hashmap = {}
        for idx, val in enumerate(nums):
            if target - val in hashmap:
                return [hashmap[target - val], idx]
            hashmap[val] = idx
        return []

if __name__ == "__main__":
    solution = Solution()
    nums = [2,7,11,15]
    target = 9
    print(solution.twoSum(nums, target))
```

### 2. 49. 字母异位词分组（中等）

**题目**：将字母异位词分到同一组
**核心思路**：异位词排序后字符串相同，用排序后的字符串作为字典key
**易错点**：list不能作为字典key，必须转为字符串/元组

```
from collections import defaultdict
class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        d = defaultdict(list)
        for s in strs:
            key = ''.join(sorted(s))
            d[key].append(s)
        return list(d.values())

if __name__ == "__main__":
    solution = Solution()
    strs = ["eat","tea","tan","ate","nat","bat"]
    print(solution.groupAnagrams(strs))
```

### 3. 128. 最长连续序列（中等）✅已写

**题目**：未排序数组，找出最长连续数字序列长度
**核心思路**：set去重；只从序列起点（x-1不在集合）向后遍历，保证整体O(n)
**易错点**：不要排序（排序复杂度O(nlogn)，不是最优）

```
class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        net_set=set(nums)
        max_len=0
        for x in net_set:
            if (x-1) not in net_set:
                num=x
                num_len=1
                while (num+1) in net_set:
                    num+=1
                    num_len+=1
                if num_len>max_len:
                    max_len=num_len
        return max_len

if __name__=="__main__":
    nums=[100,4,200,1,3,2]
    print(Solution().longestConsecutive(nums))
```

## 二、双指针

> 
> 两类：同向快慢指针、对撞左右指针；尽量减少一层循环，降时间复杂度

### 1. 283. 移动零（简单）

**题目**：数组内把0全部移到末尾，保持非0元素相对顺序
**核心思路**：快慢同向指针，慢指针标记非0存放位置，快指针遍历
**易错点**：原地修改，不能新开数组

```
class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1

if __name__ == "__main__":
    solution = Solution()
    nums = [0,1,0,3,12]
    solution.moveZeroes(nums)
    print(nums)
```

### 2. 11. 盛最多水的容器（中等）✅已写

**题目**：竖线高度数组，选两根线，求能装最多水的面积
**核心思路**：左右对撞双指针；面积由短板决定，移动短边柱子
**易错点**：移动长边一定不会得到更大面积

```
class Solution:
    def maxArea(self, height: list[int]) -> int:
        left=0
        right=len(height)-1
        max_area=0
        while left<right:
            width=right-left
            h=min(height[right],height[left])
            current_area=h*width
            if current_area>max_area:
                max_area=current_area
            if height[left]<height[right]:
                left+=1
            else:
                right-=1
        return max_area

if __name__=="__main__":
    solution=Solution()
    height=[1,8,6,2,5,4,8,3,7]
    print(solution.maxArea(height))
```

### 3. 15. 三数之和（中等）✅已写

**题目**：数组找出全部三元组 a+b+c=0，不能重复
**核心思路**：数组排序，固定i，left、right对撞双指针；三处去重
**易错点**：i去重、命中答案后左右指针去重

```
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        res=[]
        nums.sort()
        n=len(nums)
        for i in range(n):
            if i>0 and nums[i]==nums[i-1]:
                continue
            left=i+1
            right=n-1
            while left<right:
                total=nums[i]+nums[left]+nums[right]
                if total==0:
                    res.append([nums[i],nums[left],nums[right]])
                    while left<right and nums[left]==nums[left+1]:
                        left+=1
                    while left<right and nums[right]==nums[right-1]:
                        right-=1
                    left+=1
                    right-=1
                elif total<0:
                    left+=1
                elif total>0:
                    right-=1
        return res

if __name__=="__main__":
    nums=[-1,0,1,2,-1,-4]
    solution=Solution()
    print(solution.threeSum(nums))
```

### 4. 42. 接雨水（困难）

**题目**：高度数组，求总共能接住多少雨水
**核心思路**：对撞双指针，维护左右两侧最大高度；哪边max更小，处理哪边
**易错点**：每个位置储水量 = 两侧较小最大值 - 当前高度

```
class Solution:
    def trap(self, height: list[int]) -> int:
        l, r = 0, len(height)-1
        lmax, rmax, res = 0,0,0
        while l<r:
            if height[l] < height[r]:
                lmax = max(lmax, height[l])
                res += lmax - height[l]
                l +=1
            else:
                rmax = max(rmax, height[r])
                res += rmax - height[r]
                r -=1
        return res

if __name__ == "__main__":
    solution = Solution()
    height = [0,1,0,2,1,0,1,3,2,1,2,1]
    print(solution.trap(height))
```

## 三、滑动窗口

> 
> 通用模板：右边界不断扩张；窗口满足条件时收缩左边界，记录最优解；适合字符串、正数数组
> 特殊：单调队列属于滑动窗口进阶（239）

### 1. 3. 无重复字符的最长子串（中等）

**题目**：字符串，找出不含重复字符的最长子串长度
**核心思路**：哈希记录字符最后一次出现下标；遇到重复，左边界跳到重复字符下一位
**易错点**：重复字符下标必须 >= 当前左边界，才更新左边界

```
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        d = {}
        l = 0
        ans = 0
        for r, c in enumerate(s):
            if c in d and d[c] >= l:
                l = d[c] + 1
            d[c] = r
            ans = max(ans, r-l+1)
        return ans

if __name__ == "__main__":
    solution = Solution()
    s = "abcabcbb"
    print(solution.lengthOfLongestSubstring(s))
```

### 2. 438. 找到字符串中所有字母异位词（中等）

**题目**：s里面找所有p的异位词起始下标，窗口固定大小
**核心思路**：固定窗口大小，字符计数数组比较；维护匹配计数优化比对
**易错点**：窗口大小固定等于len(p)

```
class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        res = []
        count_s = [0]*26
        count_p = [0]*26
        len_s = len(s)
        len_p = len(p)
        if len_s < len_p:
            return res
        for c in p:
            count_p[ord(c)-ord('a')] += 1
        # 初始化第一个窗口
        for i in range(len_p):
            count_s[ord(s[i])-ord('a')] += 1
        if count_s == count_p:
            res.append(0)
        # 滑动
        for r in range(len_p, len_s):
            count_s[ord(s[r-len_p])-ord('a')] -= 1
            count_s[ord(s[r])-ord('a')] += 1
            if count_s == count_p:
                res.append(r - len_p + 1)
        return res

if __name__ == "__main__":
    solution = Solution()
    s = "cbaebabacd"
    p = "abc"
    print(solution.findAnagrams(s,p))
```

### 3. 239. 滑动窗口最大值（困难）✅已写

**题目**：固定大小滑动窗口，输出每个窗口最大值
**核心思路**：单调递减队列（deque），队列存下标，队首为窗口最大值
**易错点**：队首下标超出窗口范围要弹出；新元素把队尾更小的值全部弹出

```
from collections import deque
class Solution:
    def maxSlidingWindow(self, nums: list[int], k: int) -> list[int]:
        q=deque()
        res=[]
        for right , val in enumerate(nums):
            while q and nums[q[-1]]<=val:
                q.pop()
            q.append(right)
            while q[0]<=right-k:
                q.popleft()
            if right>=k-1:
                res.append(nums[q[0]])
        return res

if __name__ == "__main__":
    nums = [1,3,-1,-3,5,3,6,7]
    k = 3
    solution = Solution()
    result = solution.maxSlidingWindow(nums, k)
    print(result) # Output: [3, 3, 5, 5, 6, 7]
```

### 4. 76. 最小覆盖子串（困难）

**题目**：s中找出包含t所有字符的最短子串
**核心思路**：滑动窗口+字符计数；先扩右边界直到覆盖，再收缩左边界求最小
**易错点**：记录最优窗口的左右下标，不能提前break

```
from collections import defaultdict
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        need = defaultdict(int)
        window = defaultdict(int)
        for c in t:
            need[c] += 1
        left = 0
        valid = 0
        start, min_len = 0, float('inf')
        for right, c in enumerate(s):
            if c in need:
                window[c] += 1
                if window[c] == need[c]:
                    valid += 1
            # 满足覆盖条件，收缩左边界
            while valid == len(need):
                cur_len = right - left + 1
                if cur_len < min_len:
                    min_len = cur_len
                    start = left
                d = s[left]
                left += 1
                if d in need:
                    if window[d] == need[d]:
                        valid -= 1
                    window[d] -= 1
        return "" if min_len == float('inf') else s[start:start+min_len]

if __name__ == "__main__":
    solution = Solution()
    s = "ADOBECODEBANC"
    t = "ABC"
    print(solution.minWindow(s,t))
```

## 四、前缀和 · 子数组问题

> 
> 重点：数组存在负数时，滑动窗口失效，用前缀和+哈希；子数组是**连续**的

### 560. 和为 K 的子数组（中等）✅已写

**题目**：统计和等于k的连续子数组数量
**核心思路**：前缀和公式 `pre[r] - pre[l-1] = k` → `pre[l-1] = pre[r] - k`，哈希统计前缀和出现次数
**易错点**：前缀和初始 `cnt[0]=1`，处理pre刚好等于k的情况；有负数，不能双指针

```
from collections import defaultdict
class Solution:
    def subarraySum(self, nums: list[int], k: int) -> int:
        cnt = defaultdict(int)
        cnt[0] = 1
        pre = 0
        res = 0
        for v in nums:
            pre += v
            res += cnt[pre - k]
            cnt[pre] += 1
        return res

if __name__ == "__main__":
    solution = Solution()
    nums = [1,1,1]
    k = 2
    print(solution.subarraySum(nums, k))
```
